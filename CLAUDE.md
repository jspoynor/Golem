# Building the golem plugin

Read SPEC.md before doing anything. It is the contract.

- The plugin builds into ./golem/. SPEC.md and TASKS.md stay at repo root.
- TASKS.md milestone order is a constraint, not a suggestion. Do not reorder.
- Implement only the task named in the current session. Do not work ahead.
- §11 of SPEC.md lists non-goals with reasons. Do not add them back.
- Section numbers in SPEC.md are stable and referenced elsewhere. Never renumber.
- If SPEC.md is wrong, say so before building. Do not silently improve it.
